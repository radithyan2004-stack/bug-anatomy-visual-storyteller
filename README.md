# 🐛 Bug Anatomy Visual Storyteller

An AI-powered diagnostic copilot that bridges the gap between raw stack traces and intuitive human understanding. Built for developers and engineering teams to diagnose crashes faster through narrative breakdown and visual mapping.

---

## 🚀 Features
* **Detective Dossier:** Translates abstract error logs into witty, real-world analogies (e.g., plumbing disasters, traffic jams) to explain the core root cause instantly.
* **Failure Flowchart Sequence:** Automatically generates clean Mermaid.js execution flowcharts mapping out step-by-step failure chains.
* **Zero Database Overhead:** Lightweight, self-contained architecture powered by Streamlit and Groq LLMs (`llama-3.1-8b-instant`) for ultra-low latency.

---

## 🛠️ Tech Stack
* **Python**
* **Streamlit** (UI Framework)
* **LangChain-Groq** (LLM Integration)
* **Mermaid.js** (Dynamic Diagram Rendering)
